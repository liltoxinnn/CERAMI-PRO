# CeramiPro

Logiciel de gestion d'atelier de céramique — **application Windows native**.

Le projet se trouve dans le dossier [`CeramiPro/`](CeramiPro/).

```bat
cd CeramiPro
dotnet run --project src\CeramiPro.App
```

Tout est expliqué dans [`CeramiPro/README.md`](CeramiPro/README.md) :
installation, premier démarrage, sauvegarde, et construction de
l'installateur Windows.

---

*Une première version de ce logiciel avait été développée comme application
web (ASP.NET Core et Blazor). Elle a été remplacée par l'application Windows,
seule conforme au besoin de l'atelier, et retirée du dépôt. Elle reste
consultable dans l'historique, avant le commit qui l'a supprimée.*
